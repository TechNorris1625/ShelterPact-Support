# ShelterPact Community Support

Welcome to the community for **ShelterPact**, software designed for animal shelters, animal rescues, and municipal animal services.

## Get involved

- **Ask a question:** Open a discussion under *Help & Questions*.
- **Share an idea:** Use *Feature Requests*.
- **Report a problem:** Use *Bug Reports* for issues that are safe to describe publicly.
- **Learn from others:** Browse discussions, share tips, and mark helpful answers.

**Website:** https://shelterpact.com  
**Demo:** https://demo.shelterpact.com  
**Private support:** support@shelterpact.com

> **Protect sensitive information.** Discussions are public. Never post client or citizen information, personal addresses, animal owner records, confidential agency data, passwords, API keys, access tokens, internal links, or screenshots containing private information. Send sensitive cases privately to support@shelterpact.com.

## Community guidelines

Please read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and [SUPPORT.md](SUPPORT.md). This repository contains **public support information only**; it does not contain the ShelterPact application source code.

## Important

This is a community forum, not an emergency service or a substitute for direct confidential support. Do not report urgent public safety incidents here; follow your organization's established procedures.
